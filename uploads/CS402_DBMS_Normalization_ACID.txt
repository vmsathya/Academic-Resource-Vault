CHAPTER SUMMARY & KEY CONCEPTS:

1. FUNDAMENTALS OF TREE STRUCTURES:
   - Root, internal nodes, leaves, depth, height.
   - Maximum nodes at depth d: 2^d.
   - Maximum nodes in binary tree of height h: 2^(h+1) - 1.

2. BALANCED BINARY SEARCH TREES:
   - AVL Condition: For every node, |height(left) - height(right)| <= 1.
   - Search time: O(log n) guaranteed.
   - Rebalancing operations: Single Left (RR), Single Right (LL), Left-Right (LR), Right-Left (RL).

3. GRAPH TRAVERSAL ALGORITHMS:
   - Breadth-First Search (BFS): Uses Queue FIFO data structure. Finds shortest path in unweighted graph.
   - Depth-First Search (DFS): Uses Stack LIFO / Recursion. Applications: Cycle detection, topological sort.
   - Asymptotic Complexity: O(V + E) for adjacency list representation.
