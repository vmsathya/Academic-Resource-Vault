QUESTION 1: Formal Definition of Big-O Notation
Model Answer: Let f(n) and g(n) be functions from non-negative integers to real numbers.
We write f(n) = O(g(n)) if and only if there exist positive constants c and n0 such that:
    0 <= f(n) <= c * g(n)  for all n >= n0.
Marking Rubric: Definition formula (1 Mark) + Graphical interpretation & threshold n0 (1 Mark).

Node rotateRight(Node y) {
    Node x = y.left;
    Node T2 = x.right;
    x.right = y;
    y.left = T2;
    y.height = Math.max(height(y.left), height(y.right)) + 1;
    x.height = Math.max(height(x.left), height(x.right)) + 1;
    return x;
}
