Standard university paper covering OSI vs TCP/IP models, sliding window protocols, IPv4 / IPv6 header structures, subnetting, and Bellman-Ford vs OSPF.

PART A: SHORT ANSWER QUESTIONS (10 x 2 = 20 Marks)
--------------------------------------------------
1. Define Big-O asymptotic notation and state its formal mathematical definition.
2. Differentiate between an AVL Tree and a Red-Black Tree in terms of rotation bounds.
3. What is the minimum number of nodes in a complete binary tree of height 5?
4. Explain the concept of open addressing with quadratic probing in hash tables.
5. Write down the recurrence relation for Merge Sort and solve it using Master's Theorem.
6. State the properties of an Adjacency Matrix versus an Adjacency List for sparse graphs.
7. Define Topological Sorting and state the prerequisite graph condition.
8. What is the worst-case time complexity of Quick Sort, and how can randomized pivot selection avoid it?
9. Distinguish between internal fragmentation and external fragmentation.
10. State Dijkstra's algorithm greedy choice property and explain why it fails for negative edge weights.

PART B: DESCRIPTIVE & PROBLEM SOLVING QUESTIONS (5 x 16 = 80 Marks)
------------------------------------------------------------------
11. (a) Construct an AVL Tree by inserting the following sequence of keys:
        {42, 15, 88, 6, 27, 63, 94, 20, 31, 75}.
        Show every rotation (LL, RR, LR, RL) and the balance factor of every node after each step. (10 Marks)
    (b) Provide the complete Java implementation of the double left-right rotation algorithm. (6 Marks)

12. (a) Execute Dijkstra's Single Source Shortest Path Algorithm on the directed weighted graph with vertex set V={A, B, C, D, E, F}
        and starting vertex A. Tabulate the distance vector updates for each relaxation step. (12 Marks)
    (b) Analyze the time complexity when implemented with an Adjacency List and Min-Heap priority queue. (4 Marks)
